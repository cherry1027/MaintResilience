# MaintResilience

**Supplier Maintenance Excellence & Resilience Assessment**

MaintResilience is a two-page React research prototype demonstrating how supplier maintenance maturity can influence manufacturing performance, delivery reliability, and supply-chain resilience.

## Live Demo

https://maint-resilience.charanvaranasi44.workers.dev/

## Features

### Maintenance Maturity Assessment

- Select a fictional supplier and manufacturing process
- Assess five maintenance dimensions:
  - Preventive Maintenance
  - Condition Monitoring
  - Predictive Maintenance
  - Maintenance Data Quality
  - Maintenance Planning
- Calculate a Maintenance Excellence Score from 0–100
- Interactive radar chart
- Dynamically calculated KPIs:
  - OEE
  - Unplanned Downtime
  - MTBF
  - MTTR
  - Maintenance Cost
  - Delivery Reliability
- Maintenance-to-supply-chain impact flow
- Supplier Risk Matrix using maintenance maturity and supplier criticality
- Critical, High, Medium, and Low priority classifications

### Strategy Simulator

- Compare three maintenance strategies:
  - Reactive Maintenance
  - Preventive Maintenance
  - Predictive Maintenance
- Simulate impacts on:
  - Downtime
  - OEE
  - MTBF
  - Maintenance Cost
  - Quality
  - Delivery Reliability
  - Resilience Score
- Before-vs-after comparison table
- Maintenance Excellence Roadmap
- Strategy-specific recommended actions
